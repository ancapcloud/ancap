# Smart Pay WeVisOne-VL: Исследование распознавания zh-Hant — 2026-10-28

## Контекст

Задача P1 из очереди Теодора: улучшение распознавания китайского языка (zh-Hant).

Предыдущий результат (2026-10-27):
- zh-Hant провалил тест с шрифтом msyh.ttc (адрес не распознан, checksum отклонён)
- Требовалось исследовать причины и попробовать альтернативные подходы

## Методология

Тестирование на синтетических образцах (1800×550, Microsoft YaHei 48 px):
- Шрифт: msyh.ttc (Microsoft YaHei)
- Модель: WeVisOne-VL 2B
- Проверка: распознавание адреса и суммы, валидация checksum ACP

## Выводы

1. **Модель работает на 4 из 5 языков** — EN/RU/UK/DE проходят стабильно
2. **zh-Hant требует оптимизации** — проблема не в шрифте msyh.ttc (он же успешно использовался для других языков)
3. **Возможные причины:**
   - Подготовка данных для традиционного китайского отличается
   - Модель обучена преимущественно на упрощённом китайском (zh-Hans)
   - Особенности шрифта Microsoft YaHei для традиционных иероглифов
